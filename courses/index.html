More than a reading list

Learn. Practice. Review.

Every course connects explanations to practical experiments. Build an intuition, make a prediction, then investigate what actually happens.

  1. 01

    Learn the mechanism

    Start with definitions, mental models and diagrams.

  2. 02

    Work through the experiment

    Read the prerequisites, explore the code and run the supplied lab.

  3. 03

    Explain the evidence

    Check correctness, interpret measurements and decide what to investigate next.

Read the courses in your browser. Run labs in the documented Linux and Slurm environment; GPU exercises require the specified hardware and dependencies. Each course explains its setup and readiness checks.
