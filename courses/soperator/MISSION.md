# Course mission

Help an engineer read and use Slurm job commands confidently on a Soperator
cluster: request the intended resources, understand where work runs, and
interpret scheduler evidence together with application results.

The audience knows basic Linux commands, files, processes, CPUs and GPUs.
Kubernetes and Slurm are introduced from first principles. Read the lessons in
order; an experienced reader can use the syllabus outcomes as a readiness check.
No GPU course is a prerequisite. This is useful preparation before any course's
Slurm labs, and remains independently readable.

The course is text-only, with worked command examples and in-text questions
with answers. It requires no cluster access to complete. It contains no labs,
installation procedure, performance benchmark or cluster-administration runbook.
Applying an example later requires an authorized existing environment and its
site-specific resource policies. The architecture vocabulary follows Soperator
4.1.8; optional components depend on the deployed configuration.
