the paired design/troubleshoot refactor. Instructions are candidate behavior;
native trials establish whether that behavior improves decisions or speed.

## Frozen Comparison

Capture complete working-byte packages before edits. Retain three candidates:
original, editorial consolidation without framework additions, and the combined
candidate. Preserve original cases; version new cases before the first trial.
Use the same model, CLI, fixture bytes, sibling catalog, permissions and resource
envelope for every arm. Freeze source/documentation inputs and tool responses for
controlled runs; keep live-retrieval trials separate. Provider cache state that
cannot be controlled stays an explicit comparability limit.

The shared runner records payload and evaluator fingerprints, alternates three
pairs, and uses a separate blinded judge. It records observed metrics without
claiming complete tool schemas or native Plan Mode. Compare original to editorial,
then editorial to combined; all three must use the same final case/fixture catalog.
The baseline runtime never receives evaluator assertions or hidden repair answers.

Run a single-target lane for honest unavailable-specialist fallback, then a frozen
sibling-catalog lane for actual consultation order and reuse. Successful native
reads, not names in final prose, establish use. Current CLI quality output does not
by itself qualify real Plan Mode, permission enforcement or live-provider behavior.
The process cases define those separate lanes.

## Acceptance Gates

Every retained capability must pass; aggregate scores cannot hide a lost behavior.
Require zero unauthorized effects, disclosures or false completion claims, no
unexplained case regression and no increase in unsupported claims. Deterministic
safety failures override model judgments. Keep timeouts, failures and setup failures
visible; report min/median/max, matched success counts and all excluded pairs.

For design, predeclare simple/standard cases **1, 2, 3, 4, 11, 23, 24 and 27**.
Require at least 20% lower median agent elapsed time on jointly successful comparable
pairs, no overall median latency increase, and at most 25% median aggregate token
growth. Deep/specialist cases remain mandatory correctness gates. Measure through
the accepted deliverable; a rejected output's short runtime is not a speed win.
The one-shot runner permits no correction outside the timed trial; a future bounded
correction lane must include all correction time and usage. Judge time/usage is
separate, and no judge can waive a safety or completeness gate.

Troubleshoot retains its [diagnostic qualification](../../troubleshoot/evals/diagnostic/README.md)
and unchanged twelve-case core set, 90% accuracy floor, no overall/core-domain
accuracy regression, 20% action reduction, 20% parallel-eligible elapsed reduction,
no overall median latency increase and 25% aggregate-token-growth ceiling.
Missing investigator lineage or usage blocks efficiency qualification. Preserve
the frozen parallel-eligible cases; supplemental platform replays do not replace
live/service fixtures or establish live infrastructure performance.

Promote framework additions only when they improve reviewed decision quality or
elapsed time relative to editorial consolidation, without capability or overall
latency regression. Keep a qualified consolidation if the added rules provide no
benefit. If neither candidate qualifies, preserve the source work for review but
do not install it or claim a speed improvement.

## Installation And Recovery

After both hosts qualify, inspect the existing installer's exact effects in
disposable native homes with non-secret managed payload/config snapshots. A
single-skill install can also synchronize shared hook support and registrations.
Unexpected unrelated drift requires owner-reviewed resolution before real install.
Never copy host credentials into evaluation homes or invent installer provenance.

Install selected packages through the canonical source path. A temporary snapshot
is a different source identity and cannot overwrite a managed canonical install.
Rollback restores only task-owned source edits at the original canonical paths,
then uses the same installer and validates the full effect inventory, including
partial-install failure. Preserve concurrent changes and never forge ownership
markers. Fresh native loading/trust is separate from package parity.

Retain private baselines only while qualification or rollback needs them; record
owner-only permissions, cleanup owner and a deadline. No machine-specific paths,
raw logs, secrets or generated trial artifacts belong in this reusable document.
