does not define skill routing. Contract tests remain required for lifecycle and
output assertions; canonical CSV validation does not replace them.

## Frozen native verifier and browser acceptance

- A version-1 private root with no active generation accepts a new version-2
  generation without rewriting historical archives; unsupported active versions
  or unknown root markers fail before mutation.
- Changed source/install/helper bytes after successful preflight block prepare
  or the next launch, continuation, admission and cleanup boundary. Restore the
  frozen bundle before cleanup; fixes receive a fresh generation.
- Browser prose or a generic browser-uat PASS cannot qualify a trial. Require
  owned Playwright artifacts, exact record correlation and ordered API restart
  with fresh-context persistence and process cleanup.
- A native FAIL plus an incomplete peer yields FAIL, preserving both records.
- An independent reporting inspection does not pre-record workflow-statistics
  PASS. Only `validate-results` owns that transition after semantic replay;
  generic stage recording rejects the success without changing the ledger.
  Existing conflicting immutable records remain preserved in a failed trial.
- The companion plans one task and at most one active worker; an authorized
  replacement preserves failed-worker history, termination proof and repair
  budgets. With a PATH-only frozen validation environment, Python checks and
  their Python children use `-B`, pass their assertions and create no bytecode
  outside the exact write claims. Scope failures remain failures; never widen
  claims or discard earlier evidence to qualify a trial.
- Offline credential mocks use exact `not-a-secret` values in both patched
  environment input and expected driver-call assertions. The tests still prove
  configuration propagation, while the unchanged sensitive-content guard
  accepts the placeholder and rejects realistic credential literals. Actual
  runtime settings retain their declared ownership and storage.
