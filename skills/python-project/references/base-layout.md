# Base Layout

Use this baseline for every scaffold unless the user requests a different structure.

## Repository Tree

```text
.
├── README.md
├── CHANGELOG.md
├── LICENSE
├── .gitignore
├── pyproject.toml
├── Makefile
├── .pre-commit-config.yaml
├── .github/
│   └── workflows/
│       └── ci.yml
├── src/
│   └── <package_name>/
│       ├── __init__.py
│       ├── __main__.py
│       ├── cli.py
│       ├── settings.py
│       ├── logging.py
│       └── _version.py   # generated by setuptools-scm
├── tests/
│   ├── conftest.py
│   ├── unit/
│   │   ├── test_cli.py
│   │   └── test_smoke.py
│   └── integration/
│       └── test_cli_smoke.py
├── scripts/
│   └── dev.sh
└── infra/
    └── terraform/
```

Remove optional directories only if they are out of scope.

## pyproject.toml Baseline

Use `assets/pyproject.toml.template` and replace placeholders.

Key points:

- Use PEP 621 metadata under `[project]`.
- Default to `setuptools` build backend.
- Use `setuptools-scm` for dynamic versioning from Git tags.
- Keep runtime and dev dependencies separate.
- Add optional dependency groups for profile-specific needs (`api`, `ui`, `ml`).

## .gitignore Baseline

Include at least:

- Python artifacts: `__pycache__/`, `*.py[cod]`, `.pytest_cache/`, `.ruff_cache/`, `.mypy_cache/`
- Virtual envs: `.venv/`, `venv/`, `.env/`
- Build artifacts: `build/`, `dist/`, `*.egg-info/`
- Local/secrets patterns: `*.env`, `*.local.*`, `*.key`, `*.pem`, `*.token`, `*.secret`
- Tool output: `.coverage*`, `htmlcov/`, `.tox/`, `.nox/`

Never ignore source folders broadly.

## Recommended Commands

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
python -m ruff check src tests --fix
python -m pytest -m "not integration" tests/unit
python -m pytest -m integration tests/integration
python -m build --wheel
```

## Makefile Targets

At minimum:

- `.DEFAULT_GOAL := all`
- `all`: aggregate target, typically `check + build`
- `fmt`: `ruff format`
- `lint`: `ruff check`
- `test`: alias to fast unit tests
- `test-unit`: `pytest -m "not integration" tests/unit`
- `test-integration`: `pytest -m integration tests/integration`
- `coverage`: `pytest --cov=<package_name> tests/unit`
- `build`: `python -m build --wheel`
- `check`: `lint + test-unit`

## Testing Baseline

- Default to split test lanes:
  - `tests/unit/` for fast local development.
  - `tests/integration/` for isolated smoke/integration checks.
- Add an autouse fixture in `tests/conftest.py` that blocks network access for unit tests.
- Keep unit tests focused on pure logic, validation, rendering, and CLI parsing.
- Patch external APIs, cloud clients, and subprocess boundaries in unit tests.
- Add one CLI smoke test for each user-facing command group when CLI is in scope.
- Add one config/schema validation test with realistic sample input when typed config exists.
- Fail fast in CI for lint and unit tests before packaging.
