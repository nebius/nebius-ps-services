# Merge PR

`sdlc-merge-pr` owns conditional Agentic SDLC delivery. The default boundary is a
reviewed PR. Accepted run-level opt-in permits protected direct merging and
merged-result verification for the declared repository, branch and slices.

The adapter admits exact promoted, reviewed and qualified evidence; all mandatory
criteria, current CI, repository protections, conversations and approvals must
pass. A cluster does not grant merge authority. COMMENT review attestations do
not count as GitHub approvals. Merge queues and raw CLI/API merge paths are
rejected. Compatible protected workflows must already be installed.

Ambiguous dispatch resumes through its exact broker intent. Failed result CI
reports merged, verification failed and blocks dependent slices without repeating
the merge. Subsequent source branches begin from the verified current default.

See [document delivery](../worktree/references/document-delivery.md) for schemas,
qualification, authority, recovery and source-checkout limits.
